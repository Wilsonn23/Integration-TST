🎬 MOVIEW - Movie Catalog & Chat API

MOVIEW adalah platform web interaktif yang memungkinkan pengguna menjelajahi katalog film populer dan bergabung dalam ruang obrolan khusus untuk mendiskusikan film favorit mereka secara langsung.

✨ Fitur Utama

Katalog Film: Menampilkan daftar film populer lengkap dengan poster, tahun rilis, dan rating.

Ruang Obrolan Per-Film: Pengguna dapat masuk ke ruang obrolan spesifik dengan mengklik poster film.

🛠️ Teknologi yang Digunakan
Frontend: HTML5, CSS3 (Tailwind CSS), JavaScript.

Backend: Rust

Database: SQLite

🚀 Cara Menjalankan (Installation)

Ikuti langkah-langkah berikut untuk menjalankan proyek ini di mesin lokal Anda:

1. Clone repositori ini:
```bash
git clone https://github.com/Wilsonn23/Integration-TST.git
```

2. Cari file index.html dalam repositori

3. Klik kanan pada file index.html, lalu pilih Open with > Google Chrome (atau browser favorit Anda).
